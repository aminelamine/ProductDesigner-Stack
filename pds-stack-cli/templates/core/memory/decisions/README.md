# decisions/

Décisions structurantes. L'équivalent d'un ADR, mais **design-shaped** : une décision de portée
visuelle ou systémique compte autant qu'une décision d'architecture.

Nommage : `NNN-slug.md`. `INDEX.md` est généré par `npm run memory:index`.

## Ce qui mérite une décision

Ce qui **contraint les directions futures** : un remplacement de direction produit, une règle de
structure (plein cadre, grille), un choix de système typographique, une contrainte
d'accessibilité assumée.

## Ce qui n'en mérite pas

Un choix interne à une direction. Ça vit dans `directions/`, pas ici.

> Voie **System** uniquement. En Sketch et en Standard, aucune décision n'est écrite —
> c'est le sens des trois voies.
