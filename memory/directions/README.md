# directions/

Une entrée par direction **soumise au jugement du designer** — retenue ou refusée.

Nommage : `NNN-slug.md`, numérotation continue, jamais réutilisée.
`INDEX.md` est généré par `npm run memory:index` — ne pas l'éditer.

## Ce qui déclenche une entrée

Toute direction qui a passé le gate DIRECTION, **quel que soit le verdict**. Y compris — surtout —
celles qui ont été produites puis refusées après coup : c'est là que se trouve l'information que
le brief suivant ne peut pas deviner.

## Ce qui n'en déclenche pas

Une variation à l'intérieur d'une direction déjà actée (changer une valeur de spacing, essayer
deux graisses). Ça se règle en voie Sketch et ça ne laisse pas de trace.
