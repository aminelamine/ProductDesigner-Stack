01 The inversion

The designer's creative judgment is the system's quality gate — not one input among many.

Conventional AI dev
  1. Prompt
  2. Generate
  3. Ship
  4. Design review (if there's time)

Taste arrives last. Rework is the norm.

→
PDS Stack
  1. Direction
  2. Approve the brief
  3. Build to spec
  4. Score & learn

Taste leads. Code is the execution.

i.

Direction before execution

A Quality Brief — visual direction, three defining words, constraints, references — must be explicitly approved before a single line of code is written.

ii.

Scope is sacred

Scope freezes the moment a spec hits VALIDATED. Additions require a fresh RAY cycle. No silent creep, no moving targets.

iii.

System memory

ANALYZER writes a learning after every verdict. RAY reads the three most recent before the next spec — improvements compound.

02 The crew — five agents

A small studio
that never sleeps.

  • 01

    RAY

    Architect & Strategist

    Challenges the idea before it grows. Tiers every spec T1 / T2 / T3, locks scope, and reads the latest learnings first.

    /ray
  • 02

    BOB

    Builder & Quality Director

    Writes the Quality Brief, then implements through a 6-step Ralph Loop. No code without an approved direction.

    /bob
  • 03

    ANALYZER

    Product QA & CX

    Grades every feature /20 — spec, design system, technical quality & CX — then writes the learnings that feed the next cycle.

    /analyzer
  • 04

    EVE

    Discovery · optional

    Validates that the problem is real before any brief is drafted. Kills bad ideas cheaply.

    /eve
  • 05

    SHIP

    Delivery · optional

    Runs the deployment checklist and coordinates the hand-off so nothing slips between done and live.

    /ship
03 The cycle
  1. EVE DISCOVERY

    Find a real problem

    Validate the need before spending a single token on a solution.

    → Problem brief
  2. RAY PLAN

    Tier & lock the spec

    Right-size the work, define what's out of scope, freeze it.

    → Spec · VALIDATED
  3. BOB BUILD

    Brief, then build

    Quality Brief approved up front; atomic commits per step after.

    → Quality Brief + code
  4. ANALYZER REVIEW

    Score & learn

    Graded out of 20 against the brief. The verdict gates release.

    → Score /20 + learning

↻ learnings feed back into RAY
